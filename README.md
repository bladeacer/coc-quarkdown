# coc-quarkdown

coc.nvim LSP for Quarkdown.

## Install

`:CocInstall coc-quarkdown`

## Keymaps

`nmap <silent> <C-l> <Plug>(coc-coc-quarkdown-keymap)`

## Lists

`:CocList demo_list`
